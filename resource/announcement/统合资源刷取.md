# 统合资源刷取

在日常任务中勾选“统合资源刷取”，只需设置两项：

1. **指定队伍**：按选队界面从上到下的槽位编号选择队伍1–5。所有勾选大类使用同一队伍。
2. **指定刷取的大类关卡**：多选特别军费行动、作战体能训练、兵种能力评级、载具对抗演练。

任务按大类顺序、各类内小关卡编号顺序执行，每个小关卡快速战斗一次：

| 大类 | 小关卡 |
| --- | --- |
| 特别军费行动 | 1-1至1-5 |
| 作战体能训练 | 2-1至2-4 |
| 兵种能力评级 | 3-1至3-4 |
| 载具对抗演练 | 4-1至4-5 |

启动时先确认主页，然后进入资源收集。每个大类只进入一次，结算或跳过后回到本大类地图继续下一关；切换大类时退回资源收集列表，全部完成后回主页。

- 明确未解锁或无法快速战斗：跳过并记录原因，结束时汇总。
- 体力不足：立即结束本统合任务，保留当前界面，不购买或补充体力。
- 无法确认关卡、队伍、次数、页面状态或结算：停止并提示反馈。识别失败不等同于关卡不可用。
- 未勾选大类：不进入关卡。

切换资源收集页签和选择队伍时，按固定位置点击并识别确认结果。仅在确认仍处于选择页面时有限补点，最多点击3次；已处于目标状态则不再点击。开始战斗仅提交一次，结算超时不会再次提交。

执行报告保存在`logs/integrated_resources/`。报告包含计划、实际完成关卡、队伍与次数确认结果、导航经过和停止原因。跳过或异常时，同名子目录保存截图及最近识别记录，包含文字、匹配分数和识别区域。反馈问题时请同时保留报告和对应截图，分享前注意遮盖账号信息。

本任务默认不勾选。请按需取消原“资源刷取”和“剩余体力刷取”，避免其他任务额外消耗体力。体力不足只结束本统合任务，不会修改其他任务的勾选状态。
